05 — Lokal & ringan

Ringan.
Lokal.
Tanpa akun.

  • Dibangun dengan Rust & TauriBukan Electron. Installer 2,6 MB dan memori sekitar 50 MB saat berjalan.
  • API key di Windows Credential ManagerKunci AI-mu tidak pernah masuk ke berkas pengaturan, dan hanya dibaca oleh sisi native aplikasi.
  • Notifikasi itu opsionalMati secara bawaan, butuh izin Windows, dan isinya bisa disembunyikan saat berbagi layar.
  • Tanpa telemetriAplikasi hanya menghubungi layanan yang memang kamu pakai: harga, lirik, cuaca, data olahraga, kalender, dan penyedia AI pilihanmu.
  • Pembacaan tab hanya posisiDeteksi tab memakai UI Automation Windows untuk membaca letak tab, bukan judul atau isi halaman.

07 — Pertanyaan

Sebelum kamu
bertanya.

Dari mana data harga berasal, dan seakurat apa?

Dari Yahoo Finance, tertunda sekitar 15 menit untuk sebagian bursa. Emas dan perak dalam Rupiah adalah harga spot (XAU/XAG × USD/IDR) dan belum termasuk premi ritel seperti harga Antam. Jangan dipakai sebagai satu-satunya dasar keputusan investasi.

Apakah jadwal shalatnya sama persis dengan Kemenag?

Dihitung offline di perangkatmu dengan metode Kemenag RI (juga tersedia MWL, ISNA, dan Umm al-Qura). Bisa berbeda satu sampai dua menit dari jadwal resmi, dan zona waktunya mengikuti Windows. Bandingkan dengan jadwal resmi untuk kotamu.

Kenapa Windows menampilkan peringatan SmartScreen?

Karena installer belum ditandatangani dengan sertifikat penerbit (sertifikat semacam itu berbayar). Ini normal untuk aplikasi baru. Kamu bisa memeriksa kode sumbernya atau membangun installer sendiri.

Apakah ada data yang dikirim ke server kalian?

Tidak ada server Kuncung dan tidak ada telemetri. Aplikasi hanya menghubungi layanan yang kamu pakai: Yahoo Finance (harga), LRCLIB (lirik), Open-Meteo (cuaca), ESPN, Jolpica, MotoGP.com, dan Wikipedia (data serta foto olahraga), Google Translate atau MyMemory (hanya saat kamu memakai tab Translate, dan teks yang kamu ketik dikirim ke layanan itu), alamat iCal kalendermu, dan penyedia AI yang kamu pilih bila fitur itu dinyalakan.

Kenapa notch mengecil saat saya membuka Chrome?

Itu deteksi tab cerdas: notch mengecil jadi garis tipis hanya jika deretan tab browser sampai di bawah area notch. Dengan satu atau dua tab, notch tetap normal. Aplikasi yang diperlakukan seperti ini bisa diatur, dan fiturnya bisa dimatikan di Pengaturan.

Kenapa namanya Kuncung?

Kuncung adalah kata Jawa untuk jambul rambut yang dibiarkan tumbuh di dahi anak. Notch pun menggantung di tepi atas layar, persis seperti kuncung di dahi. Wajah bulat berponi di sisi kiri notch adalah maskotnya: matanya mengikuti kursormu.

Dari mana data olahraganya, dan apakah gratis?

Dari API publik tanpa API key: ESPN untuk sepak bola, Jolpica untuk F1, dan situs hasil resmi MotoGP.com untuk MotoGP, Moto2, dan Moto3. Foto pembalap F1 berasal dari Wikipedia, foto MotoGP dari motogp.com. Datanya bisa tertunda beberapa menit, dan bila server sedang gagal aplikasi memakai data tersimpan terakhir.

Bahasa apa saja yang didukung?

English (bawaan) dan Indonesia. Ganti di Pengaturan > Umum > Bahasa; aplikasi memuat ulang sebentar. Teks, tanggal, angka, dan menu tray ikut berganti.

Apakah mendukung banyak monitor?

Saat ini notch tampil di monitor utama. Dukungan banyak monitor belum ada.

Bagaimana cara mengganti pintasan atau mematikan fitur tertentu?

Semua ada di Pengaturan: gaya, ukuran, apa yang berputar di notch tertutup, pintasan global, kalender, AI, notifikasi, dan autostart saat Windows menyala.
